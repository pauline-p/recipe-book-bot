# Книга рецептов

Личный Telegram-бот и приложение внутри Telegram для рецептов: добавление текстом, скриншотом или голосовым, КБЖУ на 100 г, фото готового блюда.

Запуск на хостинге: `python run.py` (настройки в `amvera.yml`, переменные окружения описаны в `.env.example`).

## Обновления

Код обновляется на Amvera сам: после каждого push в ветку `main` Amvera забирает свежую версию и пересобирает бота.
