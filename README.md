# Книга рецептов

Личный Telegram-бот и приложение внутри Telegram для рецептов: добавление текстом, скриншотом или голосовым, КБЖУ на 100 г, фото готового блюда.

Запуск на хостинге: `python run.py` (настройки в `amvera.yml`, переменные окружения описаны в `.env.example`).

## Друзья

У каждого человека своя отдельная книга. Владельцы бота — id из переменной `ALLOWED_USER_IDS`.
Владелец пишет боту `/invite` и пересылает одноразовую ссылку (живёт 7 дней): кто её откроет,
получит свою книгу. `/people` — список гостей, там же можно закрыть доступ (рецепты гостя сохранятся).
У гостей лимит разборов рецептов ИИ в день — `AI_DAILY_LIMIT` (по умолчанию 20), у владельцев лимита нет.
Если `ALLOWED_USER_IDS` пустая, ботом может пользоваться кто угодно.

## Обновления

Код обновляется на Amvera сам: после каждого push в ветку `main` Amvera забирает свежую версию и пересобирает бота.
